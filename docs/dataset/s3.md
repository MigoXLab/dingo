# S3 数据集使用指南

## 概述

Dingo 可以从 AWS S3 以及 Ceph、MinIO 等 S3 兼容对象存储中读取数据，并将对象内容交给现有评估器处理。

当前 S3 数据源支持：

- 单个对象读取；
- 按前缀读取目录下的对象；
- 分页、流式读取前缀下的全部对象；
- `jsonl`、`ms_swift` 和 `plaintext` 三种逐行数据格式；
- `auto`、`path`、`virtual` 三种 S3 寻址方式；
- 自定义 endpoint，适用于 Ceph、MinIO 等私有部署。

## 安装依赖

S3 依赖已经包含在 Dingo 的默认安装中：

```bash
pip install dingo-python
```

底层使用 `boto3` 和 `botocore` 访问对象存储。

## 配置参数

### `input_path`

S3 数据源要求 `input_path` 使用完整的 S3 URI：

```text
s3://<bucket>/<object-key-or-prefix>
```

示例：

```text
# 单个对象
s3://example-bucket/datasets/train.jsonl

# 对象前缀；末尾必须保留 /
s3://example-bucket/datasets/2026-11-05/
```

Bucket 由 URI 自动解析，不需要也不支持单独配置 `s3_bucket`。

### `DatasetS3ConfigArgs`

| 参数 | 类型 | 默认值 | 必填 | 说明 |
|------|------|--------|------|------|
| `s3_ak` | str | `""` | 是 | S3 Access Key；运行时不能为空 |
| `s3_sk` | str | `""` | 是 | S3 Secret Key；运行时不能为空 |
| `s3_endpoint_url` | str | `""` | 是 | S3 服务地址，例如 `https://s3.amazonaws.com` 或私有 Ceph/MinIO 地址 |
| `s3_addressing_style` | str | `"path"` | 否 | 寻址方式，可选 `auto`、`path`、`virtual` |

## 寻址方式

假设配置如下：

```text
input_path = s3://example-bucket/data/train.jsonl
endpoint   = http://storage.example.com
```

不同寻址方式生成的 HTTP 地址不同：

| 值 | 请求形式 | 典型场景 |
|----|----------|----------|
| `path` | `http://storage.example.com/example-bucket/data/train.jsonl` | Ceph、MinIO 和多数私有 S3 兼容服务 |
| `virtual` | `http://example-bucket.storage.example.com/data/train.jsonl` | 已配置 Bucket 子域名和对应 DNS/证书的服务 |
| `auto` | 由 botocore 自动选择 | 标准 AWS S3 或确认自动判断可靠的环境 |

私有 endpoint 通常优先使用 `path`。如果误用 `virtual`，可能出现 DNS 解析失败、TLS 证书不匹配或签名校验失败。

## SDK 使用示例

下面使用占位符展示配置结构；实际使用时替换为对应连接信息，不要把真实凭证提交到代码仓库：

```python
from dingo.config import InputArgs
from dingo.exec import Executor

input_args = InputArgs(**{
    "input_path": "s3://example-bucket/datasets/train.jsonl",
    "dataset": {
        "source": "s3",
        "format": "jsonl",
        "s3_config": {
            "s3_ak": "<access-key>",
            "s3_sk": "<secret-key>",
            "s3_endpoint_url": "http://storage.example.com",
            "s3_addressing_style": "path",
        },
    },
    "evaluator": [
        {
            "fields": {"content": "content"},
            "evals": [{"name": "RuleColonEnd"}],
        }
    ],
})

executor = Executor.exec_map["local"](input_args)
result = executor.execute()
print(result)
```

## 读取对象前缀

当 `input_path` 以 `/` 结尾时，Dingo 将其作为对象前缀：

```python
"input_path": "s3://example-bucket/datasets/train/"
```

当前缀配合 `format="jsonl"` 或 `format="ms_swift"` 使用时，只读取 Key 以 `.jsonl` 结尾的对象，扩展名匹配不区分大小写；其他对象会被跳过。`format="plaintext"` 不按扩展名过滤。

不以 `/` 结尾时，Dingo 将其作为单个对象 Key：

```python
"input_path": "s3://example-bucket/datasets/train/part-0001.jsonl"
```

单个对象 Key 不校验扩展名，其内容仍按配置的 `format` 逐行转换。

前缀读取使用 S3 `list_objects_v2` 分页器遍历全部对象，不受单次最多返回 1000 个对象的限制。读取过程是惰性的：每次只打开当前对象，逐行消费并关闭响应体后再读取下一个对象，不会一次性把前缀下所有对象加载到内存或同时打开所有响应体。

对象列表仍按 S3 服务端分页返回，因此内存中会保留当前页的对象元数据；对象内容不会整文件缓存。

## 数据格式

### JSONL

配置：

```python
"dataset": {
    "source": "s3",
    "format": "jsonl",
    "s3_config": {...}
}
```

对象内容必须为 UTF-8 编码，每行是一个完整 JSON 对象：

```jsonl
{"id": "1", "content": "第一条数据"}
{"id": "2", "content": "第二条数据"}
```

### Plaintext

配置：

```python
"dataset": {
    "source": "s3",
    "format": "plaintext",
    "s3_config": {...}
}
```

对象按 UTF-8 文本逐行读取，每行转换成：

```json
{"content": "当前行内容"}
```

### MS-Swift

配置：

```python
"dataset": {
    "source": "s3",
    "format": "ms_swift",
    "s3_config": {...}
}
```

对象必须是 UTF-8 编码的 JSONL，每行是一条包含 `messages` 数组的 Agent 轨迹。S3 负责逐行读取，后续转换和指标派生行为与本地 `ms_swift` 数据集一致。字段映射和支持的 Agent 指标见 [ms-swift converter 用户说明](../agent_trace/ms_swift.md)。

S3 数据源不支持其他格式；`json`、`listjson` 等整文件格式需要先转换成 JSONL，或者改用本地数据源。

## 安全说明

- 不要在源码、配置模板、日志或报告中提交真实 AK/SK。
- 建议通过部署系统的 Secret 配置或专用密钥管理系统注入凭证。
- Dingo 的 `summary.json` 配置快照不会写入 `s3_ak` 和 `s3_sk`。
- 凭证应遵循最小权限原则，仅授予目标 Bucket/Prefix 的 `ListBucket` 和 `GetObject` 权限。
- 如果凭证曾经提交到 Git，即使之后删除，也应立即吊销并重新签发。

## 故障排查

### `S3 input_path must be a full URI`

`input_path` 缺少 `s3://` 或 Bucket。应改为：

```text
s3://bucket-name/path/to/data.jsonl
```

### `S3 param must be set when using S3 datasource`

`s3_ak`、`s3_sk` 或 `s3_endpoint_url` 为空。检查传入 `InputArgs` 的 `s3_config` 是否填写完整。

### DNS 解析失败或证书域名不匹配

私有 Ceph/MinIO 通常需要：

```python
"s3_addressing_style": "path"
```

### `AccessDenied`

检查：

1. AK/SK 是否正确；
2. endpoint 是否对应同一个对象存储环境；
3. 是否具有 Bucket 列举权限；
4. 是否具有目标对象的读取权限；
5. 系统时间是否准确，避免签名时间偏差。

### 目录读取没有返回对象

确认 URI 中的前缀大小写、分隔符和末尾 `/` 是否正确。S3 Key 区分大小写。
